# monokit

[![codecov](https://codecov.io/gh/ifiokjr/monokit/branch/main/graph/badge.svg)](https://codecov.io/gh/ifiokjr/monokit)

[![Book](https://img.shields.io/badge/book-ifiokjr.github.io%2Fmonokit-blue)](https://ifiokjr.github.io/monokit/)

This is a minimal reservation crate used to preserve the `monokit` package name.

For production usage, install and run the CLI package:

```bash
cargo install --path ../monokit_cli
```

Or use the implementation crates directly:

- `monokit_cli`
- `monokit_daemon`
- `monokit_lsp`
- `monokit_config`
- `monokit_protocol`

**Website:** <https://ifiokjr.github.io/monokit/>
